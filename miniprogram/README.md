# Aevon 校园交流网微信小程序

这是独立的原生微信小程序前端，复用现有 Node.js API；不会修改线上网站，也不包含服务端数据或收款资料。

## 当前实现

- 首页、五个频道、任务发布、未接订单和接单积分确认。
- 登录/注册复用网站账号；个人中心、积分流水、人工审核充值、建议反馈。
- 我的订单、本人删除的未接任务恢复、交易私聊、私聊图片查看和发送。
- 三步交易状态按钮：接单人标记完成、发布人确认交付并线下付款、接单人核实到账后确认收款；免付款完成也要求双方确认。
- 周榜与合格奖励的私密收款码提交。
- 用户协议与隐私说明，登录/注册前需确认。

后台权限配置、用户封禁/删号、管理员审核与线下打款仍在现有管理网站操作；本目录目前不含原生管理员后台。

## 微信开发者工具

1. 用微信开发者工具打开本目录。
2. 将 `project.config.json` 的 `touristappid` 替换成小程序账号的 AppID；正式上传必须使用已注册主体的 AppID。
3. 在小程序后台的服务器域名设置中，将 `plgslzlexpmy.sealoshzh.site` 加入 `request` 和 `downloadFile` 合法域名。当前图片上传通过 `wx.request` 发送原始图片字节，不使用 `uploadFile`。
4. 开发者工具保持“校验合法域名”开启，逐页检查布局、登录态和 API。`app.js` 中的 API 地址指向现有正式服务。
5. 小程序的名称、服务类目、隐私保护指引、用户数据处理说明和审核发布需在真实主体账号中完成。
